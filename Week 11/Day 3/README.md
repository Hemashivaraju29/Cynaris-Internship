# W11D3 – Apache Superset: Custom Dashboard for Stakeholders

## Objective
Build an interactive business intelligence dashboard using Apache Superset to present sales performance insights to stakeholders.

## Dataset
Source: `Week 07/Day 3/Sales_Data.csv`

The dataset contains 24 sales transactions with Date, Region, Category, Sales, and Units Sold columns.

## Tools Used
- Apache Superset
- Docker Desktop and Docker Compose
- PostgreSQL
- MySQL
- CSV
- Google Chrome
- Git and GitHub

## Dashboard Charts
1. Sales by Region – Bar Chart
2. Monthly Sales Trend – Line Chart
3. Sales by Category – Pie Chart
4. Sales Transactions Table – Table
5. Total Sales – Metric Card

## Key Findings
- Total sales: INR 308,400
- Average transaction value: INR 12,850
- Total units sold: 1,079
- Highest-performing region: South (INR 89,200)
- Highest-revenue category: Electronics (INR 133,000)
- Highest-sales month: June (INR 43,000)

## Steps to Share the Dashboard with Stakeholders
1. Open Apache Superset and sign in.
2. Navigate to Dashboards.
3. Open Cynaris Sales Executive Dashboard.
4. Ensure the dashboard is saved and the required charts are visible.
5. Share the dashboard URL with authorized Superset users who have the required permissions.
6. Alternatively, share the exported dashboard screenshot or PDF through approved company communication channels.
7. Ensure recipients have appropriate access permissions before sharing business data.

## Conclusion
The project demonstrates how Apache Superset can transform sales data into interactive visualizations and a stakeholder-friendly dashboard for business decision-making.
